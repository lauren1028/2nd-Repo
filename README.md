# 2nd-Repo
In this file I am inputing the code to figure out a persons BMI. I am asking the user to input the weight and height then calculating the height * 0.0254. Then the weight * 0.453592. Then calculating the bmi which is the weight divided by the (height **2) * 703. After getting the calculation it will use the round function to round the bmi 2 decimal places and print the output of the BMI.
